# MovieLog

一个移动端优先的观影数据记录与洞察应用（手机体验优先）。

## 功能亮点

- 🎬 **观影记录**：录入片名、类型、评分、日期、时长和观后感。
- 📊 **自动分析**：实时统计累计观影数、平均评分、本月观影进度、总观影时长。
- 🧠 **洞察视图**：分析偏好类型，并用条形图展示不同类型分布。
- 🕘 **最近记录**：自动展示最近 5 条观影日志，便于快速复盘。
- 💾 **本地持久化**：使用 `localStorage` 保存记录，刷新页面不丢数据。

## 快速开始

```bash
python3 -m http.server 5173
```

打开浏览器访问：`http://localhost:5173`

> 也可使用任意静态服务器（如 `npx serve`）运行。
